# מבזקון (Mivzakon) – מערכת התראות מבזקים חכמה ללא כפילויות 🔔

אפליקציית חדשות חכמה בזמן אמת, המנטרת את כל ערוצי המבזקים ואתרי החדשות המובילים בישראל (Ynet, וואלה, N12, מעריב, כאן 11, ישראל היום וערוץ 7), ומספקת **התראה אחת בלבד לכל אירוע חדשותי** בנושאים שהוגדרו (למשל: מלחמה בתימן, מלחמת רוסיה-אוקראינה, בחירות ארה"ב, פיגועים ויירוטים).

---

## 🌟 תכונות מרכזיות

1. **מנוע Deduplication & Event Clustering סמנטי בעברית**:
   - זיהוי אוטומטי ששתי כותרות/ידיעות מאתרים שונים עוסקות באותו אירוע.
   - התראה קופצת **פעם אחת בלבד** בדיווח הראשוני.
   - דיווחים עוקבים מאתרים אחרים מצורפים תחת אותו אירוע כקישורים נוספים **ללא שליחת התראה חוזרת** וללא הצפה!
2. **מקורות חדשות ישראליים נתמכים**:
   - Ynet מבזקים + Ynet ראשי
   - וואלה מבזקים + וואלה חדשות
   - מבזקי ערוצים (N12, כאן 11, מעריב, הארץ דרך גוגל ניוז)
   - ישראל היום
   - ערוץ 7
3. **התראות מיידיות בזמן אמת**:
   - התראות שולחן עבודה (Desktop Web Notifications).
   - צליל התראה מובנה עדין (Web Audio API).
   - שידור חי ב-Server-Sent Events (SSE) בעת קליטת מבזק חדש.
4. **ניהול נושאי מעקב חי**:
   - הוספה, עריכה, מחיקה והפעלה/כיבוי של נושאים ומילות מפתח בלחיצת כפתור דרך הממשק.
5. **ממשק משתמש מודרני בעברית (RTL)**:
   - עיצוב Dark Mode מודרני מבוסס Tailwind CSS.
   - מונה סטטיסטיקה חי (אירועים, כפילויות שנמנעו, מבזקים שנסרקו).
   - חיפוש וסינון מהיר לפי נושא ומילות חיפוש.

## 🚀 הרצה מקומית

1. הפעלת השרת:
   ```bash
   npm start
   ```
2. גש בדפדפן לכתובת:
   👉 **http://localhost:3000**
3. לחץ על **"הפעל התראות דסקטופ"** ואשר את ההרשאה בדפדפן.

---

## 💾 מסד הנתונים (Database)

כל הנתונים נשמרים כעת במסד נתונים **SQLite** רלציוני מלא:
* **מיקום הקובץ:** `data/news.db`
* **טבלאות:**
  * `topics` – נושאי המעקב ומילות המפתח (כולל אפשרות עריכה חיה).
  * `clusters` – כל האירועים והמבזקים המאוחדים.
  * `cluster_sources` – כל האתרים והקישורים שדיווחו על כל אירוע.
  * `settings` – הגדרות מערכת וסף דמיון סמנטי.
* תמיכה מלאה במצב WAL (Write-Ahead Logging) ואינדקסים מהירים לביצועים גבוהים.

## 📱 גישה מהסמארטפון (Mobile Access)

### אפשרות 1: באותה רשת Wi-Fi בבית/במשרד (מיידי ופרטי)
1. פתח את הדפדפן בסמארטפון וגלוש לכתובת המקומית של המחשב שלך:
   👉 **http://192.168.1.178:3000**
2. לחלופין, לחץ על הכפתור **"📱 חיבור מהסמארטפון"** בממשק במחשב וסרוק את קוד ה-QR עם מצלמת הטלפון!

### אפשרות 2: גישה מכל מקום בעולם (סלולרי 4G/5G ו-HTTPS)
כדי לגשת לאפליקציה גם מחוץ לבית ולקבל התראות Push בסמארטפון:
```bash
npm run tunnel
```
הפקודה תיצור כתובת אינטרנט מאובטחת וחינמית (`https://...localtunnel.me`) אותה ניתן לפתוח מכל מכשיר בעולם.
